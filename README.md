# 📌 Projetos em destaque

## 🧩 SkillMatch JS

Sistema desenvolvido para comparar as habilidades de candidatos com os requisitos de vagas.

Entre as funcionalidades estão:

* análise de compatibilidade;
* classificação de vagas;
* identificação de habilidades faltantes;
* busca pela melhor vaga para determinado candidato;
* manipulação de dados com JavaScript;
* versão web com interface gráfica.

### Tecnologias

`JavaScript` `HTML` `CSS`

🔗 **Repositório:**
https://github.com/PauloFilartiga/skillmatch-js

---

## 🛒 Checkout React

Aplicação de checkout desenvolvida em React simulando o fluxo de uma compra.

O projeto possui:

* carrinho de compras;
* cálculo automático de quantidade e valor total;
* navegação entre páginas;
* página de pagamento;
* validação de formulário;
* telas de sucesso e falha.

### Tecnologias

`React` `JavaScript` `Vite` `React Router` `React Hook Form` `Zod`

🔗 **Repositório:**
https://github.com/PauloFilartiga/checkout-react
